# 10 — TO BUY: shared iPhone-friendly shopping and household notes

Build a realtime household list/board, similar in feel to a shared iOS Note but authoritative in HOMEBASE. Parents access from iPhone Safari/installable PWA and wall; support multiple lists, categories/store, free text, quantities/units, optional images, priority, checked/purchased, undo, archive, recently purchased, favorites and recurring suggestions. Provide large visual pantry/shopping tile on wall; child can request items as picture cards with guardian approval rather than buy anything. Adult quick-add via keyboard/dictation, multiline paste, URL/product link (sanitized and no auto-purchase), optional voice on explicit tap. Preserve item provenance, edit history and revisions; two parents editing simultaneously must converge, including offline additions. Offer groceries vs general to-buy posts, filters, grouping, shareable text and export. Do not expose lists publicly.

Integrate iPhone pragmatically: PWA home screen, authenticated mobile deep link, and Apple Shortcuts guide to add text via a narrowly scoped revocable endpoint using a device-specific secret stored in Keychain/Shortcuts where practical. Provide sample Shortcut setup for Siri/share sheet and export-to-Notes/Reminders using user-operated share actions or Shortcuts. Do not promise native share-target support on iOS without verification. Apple Notes lacks a supported general server-side API: see https://developer.apple.com/forums/thread/813810. A web app cannot keep an arbitrary shared iOS Note bidirectionally synced. Do not scrape iCloud.com, reverse engineer Notes protocols, or store Apple primary passwords. Optional native iOS companion via EventKit for Apple Reminders only after explicit permission; verify capabilities/background restrictions, App Store/TestFlight cost, conflict rules; see https://developer.apple.com/documentation/eventkit. Native Notes export/append is not two-way synchronization. Document which workflows are truly supported versus manual.

Acceptance: both phones and wall see added, checked, edited and deleted items promptly; duplicates and offline replay handled; Siri shortcut adds item with confirmation, expired/revoked token denied; no shopping or orders performed automatically. Optional AI categorization and dedup suggestion can be approved and must preserve original text.
