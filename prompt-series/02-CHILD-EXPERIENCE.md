# 02 — HOME: visual language and navigation

Create an exceptional, child-readable illustrated home world (e.g. a miniature village, dollhouse, enchanted island or friendly space station). Choose based on originality, clarity and performance. The UI should not resemble admin SaaS. Create coherent original characters, a friendly visual guide, tactile objects, environmental storytelling and bespoke animated module entrances. Study Training Academy's existing art direction/Glim, but coordinate asset licensing and avoid copying its map. A distinct HOMEBASE guide is fine.

Design for 27-inch 16:9 wall display, 3840x2160 physical pixels but browser CSS viewport/DPR may vary; also responsive iPhone and common tablet sizes. Test real reachability: important child controls near lower reachable portion, generous 64–96 CSS px targets where feasible, no hover-only behavior, tap-first interactions, visible back/home affordance on every view, no mandatory drag or text entry. Icons must convey actual action, not arbitrary symbols; illustrate a toothbrush, shoes, basket, piggy bank, schoolhouse, calendar and photo frame. Provide persistent short optional labels for emerging readers, spoken instructions on tap, replay speaker, caption alternatives, high contrast and reduced-motion mode. Never require sound to navigate.

Build profile picker with unique illustrations/avatars and accessible names, not colors alone. Guide demonstrates navigation on first visit (skippable). Module tiles communicate status through meaningful visual cues (e.g. filled basket, stars, next routine). Design quiet idle transitions, clear error/offline states, tactile feedback, gentle celebrations under 2 seconds. No strobing, loud surprises, excessive particle effects, infinite feeds or compulsive streaks. Avoid scoring speed unless explicitly useful and opt-in. Provide neutral recovery from accidental taps and simple one-tap undo when safe.

Explore polished art pipeline: vector scenes with layered motion, skeletal animation or lightweight 3D if hardware supports it. Create visual design system, motion tokens, sound palette, accessible components, illustration registry and asset licenses. Offer parent-configurable voice, mute, quiet hours, calm mode, theme, seasonal decor. Do not send child voice to cloud by default. Provide screenshots and actual browser traces at 4K, scaled Android landscape, portrait and iPhone; measure frame time/memory and fall back to static art. Acceptance: a non-reader can select profile, find chores, see balance, enter academy, return home and request a reward using pictures alone after one demonstration.
