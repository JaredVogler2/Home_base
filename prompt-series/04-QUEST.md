# 04 — QUEST: chores, missions and achievement

Build an animated mission board for each child. Parent creates reusable task templates with original animated picture instructions, optional spoken phrase, schedule, age band, effort, XP, verification mode, shared/individual responsibility, skip behavior and order. Examples: put blocks away, place shoes in basket, help set table, brush teeth with adult, bring laundry. Do not assign dangerous or developmentally inappropriate tasks; provide guardian review for all custom templates. Support daily, weekdays, weekly, one-off, flexible, paused and vacation schedules. Generate occurrences in household timezone; do not backfill missed tasks automatically unless requested.

Child sees a handful of immediately relevant missions, taps a picture to watch a brief demonstration, then taps a large completion button. Optional multi-step visual checklist, timer (never presented as pressure), adult-help indicator, repeat instruction, undo/request help. Completion state transitions: available → in progress → submitted → approved/credited (or auto-credit according to parent rules), returned with supportive explanation, skipped. Parent can approve in batch, mark done on behalf, edit future tasks, snooze, correct credit with reversal, and view pending. Separate mandatory household routines from optional bonus missions.

Offer friendly celebration, collectible non-monetary badges, lifetime level and progress to goals. No public leaderboard or sibling comparison; no shame, forced streaks or XP losses for noncompletion. Award spendable XP exactly once per occurrence even on repeated taps, retry and offline reconnect. Record template version, child, timestamps, actor, approval and credit reference. Create illustrated mission templates for a realistic starter household. Tests: duplicate approval, simultaneous approval, offline completion, edits to recurring template, skipped tasks, parent override, accessible non-reader journey and profile isolation.
