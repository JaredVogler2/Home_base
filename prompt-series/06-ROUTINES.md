# 06 — ROUTINES: animated real-world sequences

Implement a visual routine builder and runner. Morning, bedtime, leaving house, after daycare, cleanup, getting ready for a trip are initial templates. Each routine is a versioned sequence of steps with picture, original 2–5 second animation, optional spoken cue, optional estimated duration, help-needed flag, optional branching and optional link to a QUEST occurrence. Parents create, reorder, schedule, clone and pause routines from iPhone. Set quiet hours, day-of-week variations, shared steps and gentle reminders; no mandatory countdown or punitive timer. Keep "now / next / finished" unmistakable. Let children tap next, repeat or ask for help; offer skip with parent-configurable policy, and resume a suspended routine. A child can complete physical tasks away from screen; minimize screen dependence.

Examples: wake/sunrise, dress/shirt, toothbrush with adult, breakfast, shoes, backpack; pajamas, wash, story, lights out. Illustrations show actions rather than relying on symbols alone. Parent can mark steps done together. Record run and step start/end/completion/help/skip with coarse timestamps, not camera surveillance. Link task and routine via one canonical occurrence/credit reference to prevent double rewards. Do not award XP for basic needs by default; support optional family rules. History reports where routines take longer or require assistance without treating it as a clinical assessment. Test schedule variants, DST, interrupted run, parent editing while active, two devices and duplicate XP.
