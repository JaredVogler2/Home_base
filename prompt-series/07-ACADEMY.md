# 07 — Training Academy: preserve and connect

Inspect https://github.com/JaredVogler2/Training_Academy and its docs/CONTINUE_HERE.md, docs/PROGRESS.md, package.json, Vercel settings and storage model. As of brief preparation, README describes a static React/Vite game with 62 activities, 714 challenges, six islands plus Music Lab, synthesized narration, device-local profiles and progress, offline support; not all planned phases are complete or child-tested. Do not assume deployed URL, branches, routes or schema; verify current source and ask owner to configure actual production URL if unavailable.

Phase A: provide prominent animated schoolhouse/boat launch tile, parent configurable allowlisted HTTPS URL, one-tap launch and predictable return to HOMEBASE. Prefer top-level navigation or separate managed tab with documented kiosk behavior; iframe only if CSP/frame-ancestors, storage and touch/audio behavior genuinely support it. No leaking session tokens in query strings. Ensure child can return without Android settings or browser navigation. Preserve Academy's current local mode and standalone deployment.

Phase B (optional, only after explicit permission to change Academy repo and consent for sync): design minimal versioned progress adapter. Academy currently keeps child records local; cross-origin scripts cannot read its storage. Propose small PR to add explicit opt-in mapping of pseudonymous player ID to HOMEBASE profile, local-only default, event contract (event_id, schema_version, household/profile binding, activity code, attempt/help flag, session summary, occurred_at). Authenticated server or short-lived scoped bridge credentials; strict origin checks for any postMessage, idempotent event processing, signed/authorized binding, no broad CORS or trusting browser-supplied XP. If launch-only, show no fake progress. Consider parent-mediated export/import as fallback; offer explicit deletion and disconnect.

Reward learning participation or effort, not speed, correctness, diagnostic scores or endless repeat. Parent-configurable capped XP for eligible sessions, no duplicate credit; maintain separate Academy progress vs reward grants. Child can play without linking or earning. Parent sees aggregate practice areas and distinction between supported vs independent attempts. No new tracking by default. End-to-end test start/return, offline behavior, URL misconfiguration, disabled integration, replay and origin spoofing. Never alter original game content or existing live deployment without approval.
